# PDF 合并

## 合并

```bash
python merge.py a.pdf b.pdf -o out.pdf
```

## 拆分

```bash
python split.py in.pdf --pages 1-5 -o part.pdf
```

详见 `scripts/merge.py` 与 `references/api.md`。
